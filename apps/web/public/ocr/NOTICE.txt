CellarManager local OCR assets

The runtime is generated from the exact versions pinned in the web workspace:
- Tesseract.js 7.0.0 and tesseract.js-core 7.0.0 (Apache-2.0)
- @tesseract.js-data/fra 1.0.0 and @tesseract.js-data/eng 1.0.0 (MIT package license)

The Tesseract.js and tesseract.js-core license texts are copied into this
directory by scripts/capture/prepare_ocr_assets.mjs. Language data is fetched
from the npm packages above at build time and served only from this app's own
origin at runtime. Upstream projects:
https://github.com/naptha/tesseract.js
https://github.com/naptha/tesseract.js-core
https://github.com/naptha/tessdata
The Tesseract language data repository documents Apache-2.0 licensing:
https://github.com/tesseract-ocr/tessdata_fast/blob/main/LICENSE

No user photo or recognized text is included in these static runtime assets.
