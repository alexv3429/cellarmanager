# Gate 4: inventory of supplied shared profiles

Snapshot: 23 November 2026. This is an inventory of **shared reference
profiles**, not an analysis of one household or a request to rename wines.
It was generated on a local restore of the linked project with the curator's
current suggested and previously reviewed profile mappings. Draft 2 contains
180 windows but has not been published.

The columns below count proposed **windows**, including distinct bottle sizes:

- **Already in draft** means the same dates are already present in draft 2;
  it does not mean published.
- **Technically selectable** means the import preview can select the row; it
  does not mean its identity, evidence or dates are approved.
- **Set aside** means the preview could not establish an unambiguous shared
  identity for at least one required component. It is not a cellar-name count.

| Type | Profiles | Technically selectable | Already in draft | Set aside |
| --- | ---: | ---: | ---: | ---: |
| Producer | 46 | 3 | 39 | 419 |
| Appellation | 11 | 282 | 98 | 65 |
| Region | 1 | 4 | 36 | 0 |

The most immediate technical reasons returned for the 419 producer windows
are an unresolved shared cuvée (249), producer (75), region (57) or vintage
identity (38). The preview reports the first blocking reason, not every
reason. The 65 set-aside geographic windows have group members without a
unique shared place identity.

The separate **identity preparation** preview works at cuvée/vintage level,
not window/bottle-format level. Of 460 distinct producer keys, it can prepare
115 with the currently restored mappings; 345 need a region (305) or
appellation (40) resolved first. This is not a claim that 115 windows are
ready for publication: it is a count of identities the existing curator
workflow can review and create. Suggested place mappings must be checked;
unrelated regions must never inherit one another's dates.
