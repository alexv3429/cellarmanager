# Gate 4: inventory of supplied shared profiles

Snapshot: 23 November 2026. This is an inventory of **shared reference
profiles**, not an analysis of one household or a request to rename wines.
It was generated on a local restore of the linked project with the curator's
current suggested and previously reviewed profile mappings. Draft 2 contains
180 windows at this snapshot but had not been published. A later update on
24 November added five Burgaud estimates, 20 Viré-Clessé white appellation
fallbacks and 11 Pommard village red fallbacks. On 25 November, nine
Meursault village white estimates brought the total to 225. Subsequent
review added nine Chambolle-Musigny village red, five Puligny-Montrachet
village white, seven exact-release Mas Jullien, six Vosne-Romanée Premier
Cru, four Volnay Premier Cru and 21 exact-release Mas Cal Demoura estimates,
followed by four further Mas Cal Demoura estimates, for **281** unpublished
windows. The Mas Cal Demoura additions cover Combariolles 2014–2022 and
Terre de Jonquières and Feu Sacré 2015–2022 and use the
domaine's vintage table as context with separately identified editorial
interpretations where the three milestones are not explicit.
Terre de Jonquières 2014 and earlier remain aside: iDealwine says the wine
was previously named L'Infidèle through 2014, so the historical release
identity and appellation must be resolved instead of assuming the later name.
All 14 Vosne-Romanée and 29 Volnay Premier Cru climat names were checked and
added to the common geographic reference. For Pommard, 28 such names were
added; a version 1.0.1 of the shared profile excludes Les Perrières until its
conflicting source classification is resolved. Its remaining Premier Cru
windows have not been staged. Some unusually long geographic estimates and older
Mas Jullien releases with historical appellation questions remain aside.
The tables below remain the original snapshot, not a recomputed inventory. Pommard
Premier Cru entries remain aside pending shared geographic identity review.

The subsequent Burgaud batch reused existing producer and cuvée identities
where reviewed, created three cuvées and five vintages, and staged Chollet
2024, James 2022, Javernières 2021, La Roche 2024 and Ruyère 2024 as
editorial estimates. Côte du Py 2022 was already in the draft. James 2017's
dates need further review; Lantignié 2024 remains aside because sources name
Beaujolais-Villages where the file says Beaujolais. Two existing common Côte
du Py identities require follow-up: the automatic suggestion initially
selected a different product from the one with the existing 2022 draft.
The reviewed batch selected the latter and created no extra Côte du Py
duplicate. A tested and applied suggestion correction flags the two exact
name orders as ambiguous; it has not merged the existing duplicate. No
household wine or published window was changed.

The columns below count proposed **windows**, including distinct bottle sizes:

- **Already in draft** means the same dates are already present in draft 2;
  it does not mean published.
- **Technically selectable** means the import preview can select the row; it
  does not mean its identity, evidence or dates are approved.
- **Set aside** means the preview could not establish an unambiguous shared
  identity for at least one required component. It is not a cellar-name count.

The most immediate technical reasons returned for the 419 producer windows
are an unresolved shared cuvée (249), producer (75), region (57) or vintage
identity (38). The preview reports the first blocking reason, not every
reason. The 65 set-aside geographic windows have group members without a
unique shared place identity.

The separate **identity preparation** preview works at cuvée/vintage level,
not window/bottle-format level. Of 460 distinct producer keys, it can prepare
115 with the currently restored mappings; 345 need a region (305) or
appellation (40) resolved first. This is not a claim that 115 windows are
ready for publication: it is a count of identities the existing curator
workflow can review and create. Suggested place mappings must be checked;
unrelated regions must never inherit one another's dates.

As a read-only experiment, applying the app's **unapproved unique geographic
suggestions to the preview only** raises the technically preparable count to
327 keys, leaving 133 blocked. No suggestions were accepted or written by
this experiment. Those 327 are still identities to review, not approved
drinking windows; the preview deliberately preserves already reviewed
mappings over new suggestions.

of the producer files are preserved separately and are **not** added again to
these latest-profile totals. An earlier comparison found 345 proposal rows in
21 older producer profiles without an exact counterpart by normalized name,
colour, vintage and format; changed names can account for some differences,
so these are a review queue, not 345 confirmed missing or publishable dates.
Review them as shared-reference data, not based on one cellar's formatting.

ambiguity safeguards and cross-household publication still require final
release verification described in the release plan.
