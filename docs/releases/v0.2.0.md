# CellarManager v0.2.0

v0.2.0 is the first release of CellarManager's new local-first architecture.

This is a historical release record. Its “later milestones” section describes
the scope as understood at v0.2 release time; current sequencing is maintained
in [`../product-roadmap.md`](../product-roadmap.md).

## Highlights

- React + TypeScript + Vite web application
- Supabase PostgreSQL and Auth
- PowerSync local-first synchronization
- Cloudflare Workers Static Assets hosting
- PostgreSQL-authoritative holdings
- ADD existing wine and ADD new wine
- MOVE and REMOVE / consume
- offline queuing and local projection
- reconnect with idempotent operation replay
- self-service onboarding and household isolation
- stable browser/device registration
- cellar/location setup
- wine identity, metadata and format editing

## Migration and acceptance

The production v0.1 cellar was migrated through a deterministic,
reconciliation-backed process. The one-off migration is distinct from the
future generic product CSV import feature.

Before release, v0.2 passed the PostgreSQL pgTAP suite, web lint/tests/build,
multi-user security acceptance, account lifecycle acceptance, production
migration reconciliation, and hosted offline/reconnect inventory acceptance
followed by PostgreSQL reconciliation.

The production build also removes Vite's >500 kB JavaScript chunk warning
through dependency code splitting.

## Later milestones

The richer application shell, history UI, richer offline-state UX, expanded
wine library, CSV import/export, duplicate/merge tooling, shared households,
capture/enrichment, and purchase/value history remain post-v0.2 work.
