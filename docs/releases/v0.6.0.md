# CellarManager v0.6.0

v0.6 makes the existing local-first cellar easier to use in English or French
and reduces typing when adding wine. Recognition and lookup results are always
reviewable suggestions; they never add a wine or change stock by themselves.

## Language and entry

- The interface supports English and French preferences per account, including
  dates and numeric formatting.
- An Owner can photograph a bottle label or choose existing photos, review a
  private short-lived transcript, edit suggested wine details, and check for a
  match with wines already in the household catalogue. Camera capture can
  include the front and back labels of the **same** bottle before reading.
- Printed bottle volumes in ml, cl, or l can fill the format field when the
  label text is unambiguous. A nutrition reference such as “100 ml” does not
  become the bottle format.
- Sequential bottle entry still requires an explicit wine, quantity, location,
  and ADD confirmation for each stock change.
- Printable location QR labels can select a storage location without changing
  stock. Bottle barcodes can be linked to reviewed catalogue wines; an optional
  external product lookup sends only the code and is not a vintage authority.

## Privacy and upgrade

Label photos are temporary, private, and sent to the opted-in recognition
service only when reading begins. The recognized text is also short-lived.
The app does not create a permanent photo library. The optional v0.1 historical
enrichment restoration remains preview-first; no household import is part of
this release.

Apply committed Supabase migrations in order before deploying the v0.6 web
assets and Worker. In particular, the capture-suggestion numeric-volume
migration must be present wherever label reading is offered. Do not reset or
re-import an existing cellar. See the
